## Neu

**Die Windows-App verbindet sich mit einem Server** — #45
Wer NebenkostenFix schon auf einem Server laufen hat, zum Beispiel in Docker auf einem NAS, kann die Windows-App jetzt als Zugang dazu nutzen: Bei einer frischen Installation fragt die App vor allem anderen, wo die Daten liegen sollen: „Auf diesem Rechner arbeiten“ oder „Mit einem NebenkostenFix-Server verbinden“. Die Wahl kommt bei jedem Start wieder, bis ein Objekt angelegt ist. Später geht es über Datei → „Mit einem Server verbinden …“ oder Einstellungen → Sicherung. Die App prüft die Adresse, fragt bei `http://` noch einmal nach und startet neu. Klappt die Prüfung nicht, steht der Grund rot unter dem Knopf. Läuft der Server nur ohne Verschlüsselung, bietet die App `http://` an. Im Servermodus läuft kein lokaler Server, die lokalen Daten bleiben unberührt. Die Kopfzeile zeigt, mit welchem Server die App verbunden ist. Zurück geht es über Datei → „Auf diesem Rechner arbeiten …“ oder über den Knopf in den Einstellungen. Beim Deinstallieren fragt die App, ob auch die Einstellungen dieses Rechners weg sollen (Vorgabe Nein). Die Daten bleiben in jedem Fall. Zertifikate und Einzelheiten stehen in `docs/servermodus.md`.

**Der Prüfstand nennt die Schätzquote nach § 9a HeizkostenV**
Fehlen bei einer Heizungsanlage Ablesungen, schätzt die Abrechnung den Verbrauch. Der Prüfstand zeigt jetzt je Anlage, getrennt nach Wärme und Warmwasser, welcher Anteil der Fläche geschätzt ist. Liegt er über 25 %, darf nach § 9a Abs. 2 HeizkostenV nicht nach Verbrauch verteilt werden, und der Prüfstand rät, die Abrechnung so nicht zu verschicken. Die Schätzquote wird nur angezeigt, an den Daten und am Ergebnis ändert sich nichts.

**Formulare im Stil der App**
Dateiwähler, Kästchen, Optionsfelder und Eingabefelder sehen jetzt überall in der App gleich aus. Das englische Systemfeld „Choose File / No file chosen“ gibt es nicht mehr, auch nicht beim Einspielen einer Sicherung oder beim Umzugspaket. Die Windows-App zeigt Systemtexte auf Deutsch. Feldränder sind auch im hellen Thema und auf grauem Grund gut zu erkennen.

## Behoben

**Auf macOS und Linux bot die App einen Windows-Installer an** — #49
Wer die App aus den Quellen auf macOS oder Linux startete, bekam beim Update-Hinweis die Windows-Setup-Exe angeboten. Jetzt gibt es dort kein Installer-Angebot mehr, und „Über NebenkostenFix“ zeigt „aus dem Quellcode“. Unter Windows, im Store, in Docker und im Browser ändert sich nichts.

**Die Windows-App öffnete jede Datei mit dem Standardprogramm**
Belege und Downloads gingen aus der App direkt an das Programm, das Windows für die Dateiendung kennt. Jetzt öffnet sie nur noch PDF und Bilder direkt, alles andere bietet sie zum Speichern an. Bereits hochgeladene Belege bleiben erreichbar.

## Update

Keine Wanderung, die Datenbank bleibt, wie sie ist. Gespeicherte Abrechnungen bleiben unverändert lesbar, die Rechenregeln sind unverändert. Wer sich mit einem Server verbindet, bekommt nur einen Eintrag in `%LOCALAPPDATA%\NebenkostenFix\einstellungen.ini`. Eine ältere Version ignoriert ihn und startet wieder mit den lokalen Daten.
